This file contains the described context sequences for the ConSeqUMI pipeline, which is used to detect the UMIs and extract the target sequences. 
The adapter_sequences.txt file is used to run the pipeline.

First line: -f Template-specific primer sequence, forward
Second line: -F Amplification-specific primer sequence, forward
Third line: -r Template-specific primer sequence, reverse (not in reverse compliment!)
Fourth line: -R Amplification-specific primer sequence, reverse (not in reverse compliment!)

Cutadapt is used to detect and extract the primer sequences and also to create the reverse complement.
The maximum error rate tolerance for cutradapt is set to 0.2.

To improve UMI detection the UMI length can be specified. This should help to rescue reads in which the adapter sequence is not fully sequenced ot truncated.
